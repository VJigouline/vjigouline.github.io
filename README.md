# vjigouline.github.io

The home page at https://vjigouline.github.io/: a list of [SceneEditor](https://github.com/VJigouline/SceneEditor) and the MeerCAD libraries, with links to the [MeerCAD site](https://vjigouline.github.io/MeerCADWeb/) and each project's documentation.

It is one static page, [`index.html`](index.html). Edit it to add a project.
