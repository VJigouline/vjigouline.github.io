    MeerCAD projects

    Open-source tools for 3D and CAD in the browser by Vladimir Jigouline: SceneEditor, a three.js scene editor, and the TypeScript libraries it is built on.

    Open SceneEditor MeerCAD site GitHub

    SceneEditor

    • SceneEditor A three.js scene editor that runs in the browser. Opens glTF, Collada, STL, STEP, IFC, IGES, Rhino, DXF, Blender, FBX, OBJ, 3DS, PLY, 3MF, SVG, USD, USDZ, CityJSON and Ogre models, edits their lights and materials, and renders photorealistic images. Open it · User guide

    Libraries inside SceneEditor

    • mc-step-import Reads STEP (AP203, AP214, AP242) files into three.js, tessellating B-rep solids into watertight meshes. Documentation
    • mc-ifc-import Reads IFC building models (IFC2X3 and the IFC4 line) into three.js, with the spatial structure and property sets. Documentation
    • mc-dxf-import Reads AutoCAD DXF drawings, ASCII or binary, into three.js, with their layers, colours, blocks, hatches and 3D faces. Documentation
    • mc-blender-import Reads Blender .blend files, from version 2.5 to 5.x, into three.js without Blender, with node materials, textures, lights and cameras. Documentation
    • mc-ogre-import Reads Ogre 3D meshes, material scripts and dotScene scenes, loose or zipped, into three.js, with materials, textures, lights and cameras. Documentation
    • mc-raytracer Ray traces three.js scenes with shadows, reflections and global illumination, progressively in Web Workers. Documentation

    CAD geometry

    • mc-curves CAD curves: lines, conics, splines, NURBS and more, behind one curve interface. Documentation
    • mc-surfaces CAD surfaces: planes, quadrics, NURBS, and swept, lofted and blended surfaces. Built on mc-curves. Documentation
    • mc-solids CAD solids in boundary representation, with booleans, sections and mass properties. Built on mc-surfaces. Documentation
